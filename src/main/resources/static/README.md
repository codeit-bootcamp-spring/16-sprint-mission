# Discodeit API Playground

코랄 테마의 Spring REST API 확인용 정적 페이지입니다. 서버 코드는 수정하지 않습니다.

## 프로젝트에서 실행

`index.html`, `styles.css`, `app.js`, `assets/`를 프로젝트의 `src/main/resources/static/` 아래에 복사한 다음 Spring 애플리케이션을 실행하세요. 브라우저에서 `http://localhost:8080/` 또는 `http://localhost:8080/index.html`을 엽니다.

기본 API 주소는 `http://localhost:8080/api/v1`입니다. 서버 포트를 바꿨다면 상단의 API 서버 주소에서 수정할 수 있습니다. 정적 페이지와 API를 같은 Spring 서버에서 제공하면 브라우저의 교차 출처 요청 설정을 추가하지 않아도 됩니다.

## 들어 있는 화면

- 사용자 목록: 프로필 조회, 온라인 상태 표시, 접속 시간 갱신, 삭제
- 사용자 등록: 선택 프로필 이미지를 포함한 multipart 요청
- 로그인: 이메일/비밀번호 로그인 및 사용자 ID의 브라우저 저장
- 채널 목록/등록: 공개 채널 가입·탈퇴, 선택 멤버가 있는 비공개 채널, 빈 멤버 채널
- 메시지: 읽음 시간 경계, 작성, 수정, 삭제, 파일 첨부와 다운로드
- 샘플 데이터 만들기: 사용자와 공개·비공개 채널, 메시지를 API로 생성

사용자 데이터가 없는 서버에 처음 접속하면 테스트용 사용자 3명과 공개·비공개 채널, 메시지를 API로 한 번 생성합니다. 이미 사용자가 있으면 자동 생성하지 않습니다. `샘플 데이터 만들기` 버튼도 같은 기준으로 동작합니다. 샘플 계정은 `haneul.demo@example.com` / `DemoPass123`입니다.

## 요청 메모

- 사용자 생성은 `user` JSON 파트와 선택 `profileImage` 파트로 보냅니다.
- 메시지 생성은 `message` JSON 파트와 0개 이상의 `attachments` 파트로 보냅니다.
- 파일 바이트 배열은 `POST /api/v1/files`의 `{ "ids": [...] }` 요청으로 조회하고, 브라우저에서 미리보기/다운로드 Blob으로 바꿉니다.
- 읽음 위치는 사용자별 `lastReadTime`을 사용하며, 메시지의 `updatedAt`과 비교해 목록의 경계를 표시합니다.
- 공개 채널 가입·탈퇴는 `POST`/`DELETE /api/v1/channels/{id}/users`에 `{ "userId": "..." }`를 보내며, 가입 여부와 공개 채널 멤버 표시는 사용자별 읽음 상태 목록으로 확인합니다.
- 샘플 메시지를 만들기 전에 공개 채널 멤버를 먼저 가입시키고, 비공개 채널은 생성 시 멤버를 지정합니다.

이번 전달물에는 샘플 프로필 사진을 넣지 않았습니다. 프로필 이미지 선택 업로드와 기존 프로필 표시 기능은 포함되어 있으므로, 사용자 등록에서 직접 이미지를 선택할 수 있습니다.
